# PSL Version 0.1 Notes

## Scope

Version 0.1 establishes the foundational language surface:

- Canonical AST structure
- YAML source ingestion
- Shorthand set parsing for basic forms
- Absolute load intensity targets (`load` and `load_range`, and shorthand `@150kg` / `@[100,120]kg`)
- Calendar scheduling (start/end dates) and repeating session schedules
- Semantic validation for structural/intensity constraints
- Compilation into a normalized plan model
- Materialization into dated session instances (using calendar + schedule)
- Progression rules (`increment` / `weekly_increment`) with configurable cadence (weeks or sessions), applied during materialization using completion results

## Known Limitations

- Runtime rule engine is placeholder-only.
- Progression strategy support is minimal (currently basic increment rules only).
- No official migration tooling between versions yet.
