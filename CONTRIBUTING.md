# Contributing

## Development Setup

1. Install Node.js 20+.
2. Install dependencies with `npm install`.
3. Run checks before opening a PR:
   - `npm run lint`
   - `npm run test`
   - `npm run build`

## Pull Request Guidelines

1. Keep changes focused and atomic.
2. Add or update tests for behavioral changes.
3. Update docs/spec when language behavior changes.
4. Add a changelog entry under `CHANGELOG.md`.

## Commit Style

Use clear, imperative commit messages. Example: `Add shorthand parser validation for RPE bounds`.
